# Web Browser-Based Hybrid Cryptojacking Detection and Prevention

## Overview
This project presents a hybrid framework for detecting and preventing cryptojacking attacks in web environments. Cryptojacking is a type of cyberattack where malicious scripts exploit a user’s CPU resources for unauthorized cryptocurrency mining.

## Problem Statement
Existing anti-cryptojacking solutions often suffer from low detection accuracy, high runtime overhead, and limited adaptability to evolving attack patterns.

## Proposed Approach
The proposed system combines:
- **Static JavaScript Analysis** to detect suspicious mining scripts
- **Dynamic Runtime Monitoring** to analyze CPU usage and behavioral patterns
- **Hybrid Detection Model** for improved accuracy and performance

## Features
- Detection of hidden mining scripts
- Real-time monitoring of system resource usage
- Improved detection accuracy over existing tools
- Low runtime overhead

## Methodology
1. Collect web domains and scripts
2. Perform static analysis on JavaScript code
3. Monitor runtime behavior (CPU usage, execution patterns)
4. Identify anomalies and block malicious activity

## Results
The hybrid approach demonstrates better detection performance compared to traditional browser-based extensions, while maintaining system efficiency.
